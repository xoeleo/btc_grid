# BTC 自适应多空网格

根据用户“允许多空切换，优先提高收益”的约束研发。独立研究代码，不连接交易所，
不修改现有 Java 策略、配置、账户或运行服务。

```bash
python3 -m unittest discover -s research/adaptive_long_short_20261012 -p test_backtest.py -v
python3 research/adaptive_long_short_20261012/backtest.py
python3 research/adaptive_long_short_20261012/run_range.py
python3 research/adaptive_long_short_20261012/build_report.py
```

依赖 Python 3、numpy、pandas、matplotlib。行情来源为
`../dip_grid_500k_20261011/data`，运行前校验其 SHA256 和分钟连续性。

打开 `report.html` 阅读结论、压力结果和全部 Cycle。`results.json` 保留选择规则、
训练候选、选中参数与所有结果；`audit.json` 和 `cycle_details_audit.json` 保留独立验收。
每个场景另存成交、资金费、控制决策、小时净值与完整轮次。

## 固定规则

- 日线快线高于慢线、收盘在慢线上且快线上升时做多。
- 日线快线低于慢线且收盘在慢线下时做空。
- 其余为震荡，沿用最近明确方向，以较小仓位交易。
- 所有日线信息次日使用，小时波动信息下一小时使用；前 60 天持币为零。
- 每小时重挂上下各三层，单层 2% 净值；格距随前小时 ATR(24) 调整，限定 0.4%–1.5%。
- 每次加仓按执行后的净值校验绝对名义敞口；切换方向先平旧 Cycle，再开新 Cycle。
- 允许亏损减仓和平仓，不要求“每轮回本”；正资金费率会为空头产生收入。
- 穿透一跳才假定限价成交，每小时同单最多成交一次，不模拟真实排队与可成交量。

候选只包含 EMA 10/40、20/60 与趋势仓位 45%、65% 的四种组合；震荡仓位为趋势仓位的
37.5%，每个方向最大买入 / 卖出加仓敞口为目标 + 6 个百分点。第一年按收益减 1.5 倍
最大回撤选择，第二年冻结参数并独立从现金启动。报告也保留同参数全期持续账户结果。

研发已看过全期旧报告，时间留出属于回顾性验证，不是新的盲测数据。
训练年亏损、网格消融、资金费依赖和压力结果应一起评估，不能仅凭两年总收益宣称
“已经适应所有行情”。纯多头研发对照保留在 `../adaptive_grid_20261012`。

第二阶段 `run_range.py` 保持相同参数，只在震荡状态启用网格。这是发现原网格消融
不佳后进行的结构改进，已经看到第二年结果；所有验证都明确标为回顾性研究。
原结果保留，不得把改进的第二年结果当成重新得到的盲测证据。

这是研究模型，尚未实现实盘执行、重启恢复、账户风控与真实订单簿模型。
