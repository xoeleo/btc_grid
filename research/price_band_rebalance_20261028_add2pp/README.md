# 固定 6万—20万美元目标仓位：5点、2点与1点触发对比

研究参数来自本次用户确认，未定位到参数完全一致的原报告，因此这是按确认规则重新建立的可复现研究，不声称与旧结果逐项相同。

- 价格映射：`target = clip((200000 - BTC现货价) / 140000, 0, 1)`。60,000及以下为100%，200,000及以上为0%，130,000为50%。固定美元锚点，不随ATH更新。
- 触发：分钟开盘时，实际净BTC资产比例相对目标的绝对偏差 **>=5个百分点**、**>=2个百分点** 或 **>=1个百分点**。三个独立对称组，买卖方向各自使用本组同一阈值；不是价格涨跌阈值，不是买5点/卖1点。
- 交易：已有BTC现货数量保持不动，直接用BTCUSDT永续合约市价调回当时目标；没有网格分单。初始合约先对齐目标，后续才按阈值触发。
- 资金：初始已有BTC现货市值500,000 USDT，按各场景首分钟现货价折算；没有额外注资。既有现货不新买，不计一次新的现货建仓费，合约首次调整收费。
- 主口径：仅开空/平空，用合约对冲；空单全平后如仍达不到目标，不额外买现货或开合约多单，明确记录目标不可达时长。另列允许合约净多的对比，后者可以更完整追踪目标。
- 成本：合约taker单边0.035%，不利滑点1bp，数量步长0.001 BTC，简化最小名义5 USDT；按历史结算时间与当时持仓计入资金费。基础融资利率为0，另列负USDT余额借款年化5%/10%、手续费翻倍场景；成本变化会改变后续触发路径，并非简单从基础结果减去成本。
- 窗口：UTC `2024-10-02 00:00` 至 `2026-10-02 00:00`（右端不含），1,051,200根完整Bybit分钟线，含现货、合约成交、标记价三组OHLC，以及2,190条历史资金费。没有扩展到2026-10-28。数据复用原研究冻结档案，逐文件SHA256核验；原文件只读。
- 子区间：year1、year2分别独立从50万美元既有BTC启动，不等于完整两年组合中对应年度的接续收益；`yearly.csv`是各场景自然年分段收益，2024/2026为不完整自然年。
- 权重：`(现货BTC数量×现货价 + 合约有符号数量×标记价) / 总净权益`。总净权益含合约未实现盈亏、手续费、资金费、已计借款利息；不是只统计已平仓利润。

## 追加2点说明

2点组仅空单对冲期末785,030.17 USDT，允许合约净多期末804,581.67 USDT，调仓分别481/545次。在同一样本中，收益均低于对应的5点和1点组；相对于1点显著减少交易次数。允许净多2点组回撤43.19%，略低于5点43.21%，不能笼统说所有指标都更差。融资/费用假设会改变触发路径，敏感性场景结果不是成本的机械减法。

原D盘报告保持不动；保存副本时出现 `No such device` 写入错误，计算迁至Linux临时目录，新完整报告保存于F盘独立目录。F盘输入档案与原回测数据SHA256逐文件一致。`snapshots/before_2pp/` 保存追加前报告与结果；原45个CSV账本保持字节一致。

完整重跑：`python3 run.py`（22场景）；从追加前快照单独复现增量可使用 `run_add2pp.py`，该脚本会拒绝已包含2点组的结果，防止重复追加。
