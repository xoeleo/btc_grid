# 自适应网格研发

独立研究目录。仅读取冻结行情文件，不连接交易所，不修改现有 Java 策略、配置或运行服务。

## 运行

依赖 Python 3、numpy、pandas、matplotlib。数据复用 `../dip_grid_500k_20261011/data`。

```bash
python3 -m unittest discover -s research/adaptive_grid_20261012 -p test_backtest.py -v
python3 research/adaptive_grid_20261012/backtest.py
python3 research/adaptive_grid_20261012/build_report.py
```

打开 `report.html`。完整结果在 `results.json`，独立账本校验在 `audit.json`，逐轮校验在
`cycle_details_audit.json`。每个场景单独保留成交、资金费、小时净值、控制事件和 Cycle。

## 研发约束

- 本金 50 万 USDT，只有多头，现金约束防止杠杆。
- 日线趋势指标只在次日使用，小时波动指标只在下一小时使用；头 60 天现金预热。
- 上涨 / 震荡 / 下跌状态控制目标仓位；下跌状态可以亏损清仓。
- 小时重挂上下三层网格，单层 2% 净值；波动格距限制为 0.4%–1.5%。
- 每笔买入按实际价格和标记价核查资金与仓位容量；每小时处理价格引起的仓位漂移。
- 限价穿透一跳才可成交，一小时内不补同一层订单；穿透不是盘口成交证明。

四个候选固定为 EMA 10/40 或 20/60，趋势仓位 30% 或 45%，震荡仓位为趋势仓位的
37.5%。只用第一年收益减 1.5 倍最大回撤选参数，第二年不调参。该研发已经看过
全期旧报告，第二年只能叫回顾性时间留出验证，不能叫真正未见样本。

保留两种分钟内假设路径、仅开收价、双倍手续费 / 5bp 市价滑点、半量限价成交、
相同仓位控制关闭网格、第二年独立启动等结果。成本和成交模型变化可能改变结论。

是否通过研发门槛应以报告的第二年结果、成本压力、回撤以及网格消融为依据，
不能只看全期已平仓利润。所有未结束 Cycle 保留，报告列出清仓前仓位。

这是回测研究实现。真实排队、可成交量、断线恢复、强平与交易所账户规则尚未实现；
需要单独开发与前向 Paper 验证后，才能讨论实际运行。
